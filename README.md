# Модуль оплати AIFO для WHMCS

Модуль оплати AIFO призначений для інтеграції платіжної системи AIFO з системою управління хостингом WHMCS та забезпечує приймання онлайн-платежів, обробку результатів оплати і перевірку підпису платіжних запитів.

Для коректної роботи модуля необхідно використовувати WHMCS версії 7.0 або новішої, PHP версії 7.2 або новішої, а також активний обліковий запис у платіжній системі AIFO.

Перед встановленням модуля необхідно завантажити його файли та розмістити їх у файловій системі WHMCS. Каталог modules слід скопіювати до кореневого каталогу сайту WHMCS з дозволом на заміну файлів у разі потреби. Після копіювання перевірте, що в каталозі /modules/gateways/aifo/ розміщені файли aifo.php, aifo_success.php та aifo_fail.php.

Після встановлення файлів необхідно виконати активацію модуля в адміністративній панелі WHMCS. Для цього увійдіть до панелі керування, перейдіть до розділу налаштувань платежів та платіжних шлюзів, знайдіть модуль AIFO у списку доступних шлюзів та увімкніть його. Після активації необхідно зберегти параметри платіжної системи.

У налаштуваннях модуля необхідно вказати ідентифікатор магазину в системі AIFO та секретний ключ, отримані в особистому кабінеті платіжної системи. Секретний ключ зберігається у зашифрованому вигляді. Також необхідно вибрати тип підпису, який використовується для генерації та перевірки хешу платежів. Підтримуються алгоритми MD5, SHA256, SHA1, RIPEMD160, SHA384 та SHA512. Тип підпису повинен повністю відповідати налаштуванням, зазначеним в особистому кабінеті AIFO. У параметрі URL сервісу AIFO вказується адреса платіжного сервісу, за замовчуванням використовується https://aifo.pro.

Додатково можуть бути налаштовані параметри журналювання, IP-фільтрації та сповіщень про помилки. У разі зазначення шляху до файлу журналу виконується запис інформації про всі платіжні операції. IP-фільтр дозволяє обмежити приймання callback-повідомлень лише від довірених IP-адрес. За наявності email-адреси для помилок система надсилатиме повідомлення з описом проблеми та інформацією про платіж.

Для коректної роботи платіжної системи в особистому кабінеті AIFO необхідно вказати URL успішної оплати у форматі http://ваш-домен/modules/gateways/aifo/aifo_success.php, URL невдалої оплати у форматі http://ваш-домен/modules/gateways/aifo/aifo_fail.php та URL обробника callback у форматі http://ваш-домен/modules/gateways/aifo/aifo.php, де ваш-домен — доменне ім’я сайту з установленим WHMCS. Рекомендується використовувати захищене з’єднання HTTPS та забезпечити доступність зазначених URL з мережі Інтернет.

Формування підпису платіжного запиту виконується за формулою hash(shop_id:amount:secret_key:id), де shop_id — ідентифікатор магазину, amount — сума платежу, secret_key — секретний ключ, id — ідентифікатор інвойсу. Тип функції хешування визначається вибраним типом підпису.

Під час обробки callback-повідомлень перевірка підпису виконується за формулою hash(shop_id:sum:secret_key:invoice), де sum — сума платежу з callback-повідомлення, invoice — ідентифікатор інвойсу. Отримане значення порівнюється з підписом, переданим у параметрі http_auth_signature.

Модуль підтримує всі типи підписів, доступні в платіжній системі AIFO. Тип підпису в налаштуваннях модуля повинен збігатися з типом підпису, зазначеним в особистому кабінеті AIFO. У разі виникнення помилок рекомендується перевірити коректність параметрів, доступність URL обробника, права доступу до файлів модуля та за необхідності виконати перезавантаження веб-сервера. Для файлів модуля рекомендується використовувати права доступу 644.
